# FreeVelo

Source-available indoor cycling training app for small groups of friends – free for noncommercial use.

- Structured ERG workouts, workout editor, FTP tests, adaptive (rule-based) training plans
- Ride together with friends – **Keep Together** (group speed = average W/kg) or free mode
- Stylized 3D world, procedural routes and GPX import (real surface & vegetation from OpenStreetMap)
- Smart trainers via BLE FTMS (Tacx Neo 2, Wahoo Kickr), power meters, heart rate monitors, Zwift Click/Play
- Strava auto upload, FIT export
- Android first, later iOS & Windows · German & English

**Status:** concept phase – see [docs/CONCEPT.md](docs/CONCEPT.md).

## Tech
Unity 6 (C#) client · pure C# core libraries · Kotlin BLE plugin for Android · ASP.NET Core server
